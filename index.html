    How it works

    Smart entropy

    Plain math says P@ssw0rd2024! has 85 bits. But attackers try leetspeak words, years and keyboard walks first, so each detected pattern is charged only what it really costs to guess. That one drops to about 22 bits.

    Length beats tricks

    Each random character multiplies the work. Four random words beat a short password stuffed with symbols, and they're far easier to remember.

    Zero uploads

    No fetch(), no APIs, no analytics, no libraries. The counter above watches every network request this page makes, so you don't have to take our word for it.
